# Untrusted Clothing

This is a Next.js 15 project for the Untrusted Clothing website.

## Features

- GSAP preloader animation
- Blood droplet particle background
- Tailwind CSS styling
- React 19

## Setup

### Prerequisites

- Node.js (v18+)
- pnpm (recommended)

### Install dependencies

```bash
pnpm install
```

### Run the development server

```bash
pnpm dev
```

The app will be running at http://localhost:3000 (or next available port).

### Build for production

```bash
pnpm build
pnpm start
```
